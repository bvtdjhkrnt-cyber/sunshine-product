# 产品检索对比（1113 版）

阳光人寿 / 中国人寿 **在售与停售寿险、年金产品**的公开信息检索与收益测算工具。
纯静态页面，无后端、无账号，双击 `index.html` 即可打开。

> 数据全部来自两家公司官网公开披露的现价全表、费率表、产品说明书，
> 只做整理与换算，**不做任何插值或模拟**。

## 快速开始

| 方式 | 做法 |
| --- | --- |
| 本地打开 | 直接双击 `index.html` |
| 在线访问 | 部署到 GitHub Pages 后访问 `https://<用户名>.github.io/<仓库名>/` |
| 其他托管 | 整个目录原样上传即可，页面之间只有相对路径依赖 |


## 加载方式

收益率数据按产品拆开：首屏只加载清单和索引（约 **1.5 MB**），
点开某个产品、或把它加入对比时，才去取 `data/p/<编号>.js` 这一个文件（平均 500 KB）。

旧版是一次性加载 170 MB，现在首屏快很多；代价是第一次展开某个产品的收益率区域会有一两秒的“正在加载…”提示。

## 收益率口径

按**每千元年交保险费**换算。现金流时点是 IRR 的关键：

- **保费**在各保单年度**年初**支付（第 1 年保费在合同生效日，第 2 年保费在满 1 年时）——
  所以 3 年每年交 1 万，与趸交 3 万，算出来的年化完全不同；
- **生存金/年金**计在**年末**，**退保现价**也取目标年度**年末**；
- 目标年度末「退保 + 已领年金」合成一个时点，再倒推内部收益率。

口径说明：

- **保证年化**：只看合同保证的现金价值，不含红利、不含身故给付。
- **含红利年化**：保证现价 + 保证累积红利 + 红利累积红利，**只在说明书披露的示例模型点上成立**，
  非示例点没有红利数据，一律留空（表格上方会有小字提示）。
- **回本年限**：年金类按「累计领取 + 当年现金价值 ≥ 累计保费」判定；非年金类按现金价值判定。
- 年金产品的年化**已计入截至该年度的累计领取**。所以前几年可能很负——那不是没算年金，
  而是保费刚缴完、年金才领了几年；看第 20/30 年或期末才有比较意义。
- 计算结果只反映「退保 + 已领年金」，**不含身故给付、不含分红实现率假设**。

## 已知限制

- 官网未披露现价全表的产品（多为万能险、专属商业养老、银代定寿）不做测算，页面会写明原因。
- 少数产品官网只披露部分交费期间（如只给 3/5 年交），对应模型点无法测算，**不做外推**。
- 5 个国寿年金（GS025、GS045、GS050、GS056、GS084）的年金给付结构未能从说明书还原，
  页面上的年化仅为退保口径，会明显低于实际领取收益。
- 停售产品的数据来自历史披露文件，分析结果仅供参考，页面有提示。
